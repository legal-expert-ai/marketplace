# Security

Please report security issues privately through [GitHub Security Advisories](https://github.com/legal-expert-ai/marketplace/security/advisories/new). Do not disclose access tokens, client documents, personal data, or confidential legal matters in public issues.

Nu publicați tokenuri, documente juridice sau date de client într-un issue public. Raportați vulnerabilitățile prin canalul privat de suport Legal Expert indicat în aplicație.

Pluginul folosește OAuth pentru autentificare, iar backendul verifică utilizatorul, organizația și abonamentul la fiecare apel protejat.
